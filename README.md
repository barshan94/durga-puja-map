# Durga Puja Map

A mobile-first, privacy-first tool for extracting GPS coordinates and capture times from photos, reviewing candidate Puja visits on a map, and exporting a clean inventory.

## Privacy

Photo files are processed in your browser. This app does not upload selected photos to a server. Avoid committing photos or private location exports to this repository.

## First milestone

- Select photos from a phone or computer
- Read embedded GPS and capture time where available
- View GPS-tagged photos on a map
- Export metadata as CSV or JSON

This first milestone identifies photo locations, not confirmed Puja venues. Several photos can belong to the same venue, and GPS can be inaccurate. Review and group locations before treating them as unique venues.
